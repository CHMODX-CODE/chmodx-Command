# chmodx-Command

**Terminal Mastery for Hackers**

chmodx-Command es un programa educativo interactivo creado para enseñar comandos de Termux de forma profesional y divertida. Desarrollado para la marca **chmodx**.

## 🎯 Características

- 📚 **10 Capítulos Completos**: Desde fundamentos hasta diagnóstico avanzado
- 🎮 **Modo Interactivo**: Navegación con Rich UI
- ✅ **Verificador de Paquetes**: Verifica automáticamente paquetes instalados
- 📊 **Progreso Guardado**: Tu avance se guarda automáticamente
- 🎨 **Diseño Profesional**: Interfaz estilo hacker con Rich
- 🚀 **Instalación en 1 Comando**: Fácil de instalar y usar

## 📦 Instalación

### Instalación rápida:
```bash
curl -fsSL https://raw.githubusercontent.com/usuario/chmodx-Command/main/install.sh | bash
```

### Instalación manual:
```bash
git clone https://github.com/usuario/chmodx-Command.git
cd chmodx-Command
bash install.sh
```

## 🚀 Uso

Una vez instalado:
```bash
chmodx-command
```

## 📚 Capítulos

1. **Fundamentos de Termux** - Gestión básica
2. **Interacción con UI** - termux-api
3. **Hardware del Dispositivo** - Cámara, sensores, TTS
4. **Comunicación** - SMS, Wi-Fi, GPS
5. **Procesos y Sesión** - Control de procesos y jobs
6. **Manipulación de archivos** - grep, sed, awk
7. **Scripting** - Automatización shell
8. **Almacenamiento** - Permisos y compresión
9. **Red Avanzada** - SSH, curl, diagnóstico
10. **Internos del Sistema** - Diagnóstico avanzado

## 🛠️ Requisitos

- Termux
- Python 3.7+
- pip
- Paquetes: `rich`, `termcolor`
