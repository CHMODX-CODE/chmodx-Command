# Changelog - chmodx-Command

## [v1.0.0] - 2025-10-19

### ✨ Características
- Programa educativo interactivo para aprender comandos de Termux
- 10 capítulos completos con 100+ comandos
- Interfaz profesional con Rich
- Instalación en 1 comando
- Verificador de paquetes integrado
- Sistema de progreso y seguimiento
- Modo práctica interactivo
- Quiz de comandos
- Arte ASCII profesional

### 📚 Capítulos incluidos
1. Fundamentos de Termux
2. Interacción con la UI Android
3. Acceso al Hardware
4. Comunicación y Conectividad
5. Procesos y Gestión de Sesión
6. Manipulación Avanzada de Texto
7. Scripting y Automatización
8. Almacenamiento y Archivos
9. Red Avanzada y Seguridad
10. Internos del Sistema

### 🔧 Instalación
- Script install.sh automatizado
- Verificación de dependencias
- Instalación en ~/.chmodx-command
- Enlace simbólico automático

### 🎨 Diseño
- Colores y estilo hacker
- Paneles profesionales con Rich
- Tablas y menús interactivos
- Arte ASCII personalizado

### 📦 Requisitos
- Python 3.7+
- Termux
- Paquetes: rich, termcolor
